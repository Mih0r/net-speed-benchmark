# Замер скорости сети (Network Speed Benchmark)

Консольная утилита на Python для последовательного замера скорости скачивания и сетевой задержки при загрузке тяжелых статических файлов по протоколам HTTP/HTTPS.

## Особенности реализации
- Потоковая вычитка данных чанками по 64 КБ через `httpx.stream` для предотвращения переполнения оперативной памяти при загрузке больших файлов.
- Высокоточный замер времени соединения и передачи данных через `time.perf_counter()`.
- Отключение клиентского кеширования заголовком `Cache-Control: no-cache`.
- Гибкая настройка параметров через консольные аргументы (`argparse`).
- Безопасная обработка сетевых сбоев, таймаутов и статусов HTTP.

## Требования
- Python 3.12+
- Пакетный менеджер [uv](https://docs.astral.sh/uv/) (рекомендуется) или стандартный `pip`

## Быстрый запуск через uv

Благодаря `uv` скрипт запускается в одну команду без ручной возни с виртуальными окружениями:

```bash
uv run speed_test.py "https://images.unsplash.com/photo-1579783900882-c0d3dad7b119?w=3000"
```

Если проект клонируется локально:

```bash
git clone https://github.com/Mih0r/net-speed-benchmark.git
cd net-speed-benchmark
uv sync
uv run speed_test.py "https://images.unsplash.com/photo-1579783900882-c0d3dad7b119?w=3000"
```

## Классический запуск (без uv)

- Создать и активировать виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
```

- Установить зависимости:
```bash
pip install -r requirements.txt
```

Запустить скрипт:

```bash
python speed_test.py "https://images.unsplash.com/photo-1579783900882-c0d3dad7b119?w=3000"
```

## Параметры вызова
- `url` (обязательный) — ссылка на скачиваемый ресурс.
- `-n`, `--iterations` — количество последовательных запросов (по умолчанию **10**).
- `-t`, `--timeout` — максимальное время ожидания одного ответа в секундах (по умолчанию **30.0**).

Пример с кастомным количеством итераций и увеличенным таймаутом:

```bash
uv run speed_test.py https://nodejs.org/dist/v20.18.0/node-v20.18.0-win-x64.zip -n 5 -t 15.0
```

Пример вывода в консоль:

```bash

=== Результаты замера ===
Итераций выполнено: 5
Среднее время запроса: 1.298 сек
Средний объем ответа: 28.23 МБ
Всего скачано: 141.16 МБ
Скорость скачивания: 21.75 МБ/с
=========================
```
